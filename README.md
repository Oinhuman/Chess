# 凡人修仙传 · 围棋

纯前端单文件古风围棋游戏，支持本地天机 AI 对战与 Ollama 本地大模型对战。包含账号系统、人机对战、排行榜、存档、模型对局与修仙境界系统。

## 运行方式

### 基础模式（本地天机 AI）

直接双击打开 `weiqi.html` 即可游玩。

### 模型对局模式（Ollama 大模型）

需要启动本地 HTTP 服务器，解决 CORS 跨域限制：

```bash
cd Chess
node server.js
```

然后浏览器访问：`http://localhost:8080/weiqi.html`

> **为什么需要服务器？** 浏览器安全策略禁止 `file://` 页面向 `http://localhost:11434`（Ollama）发请求，必须通过 HTTP 服务器加载页面才能调用大模型 API。

## 游戏使用说明

### 登录入口

进入游戏后，登录界面提供以下选项：

- **登录**：输入已注册的用户名和密码进入游戏。
- **注册**：创建新账号，记录经验、等级、战绩和存档。
- **修改密码**：验证旧密码后设置新密码。
- **忘记密码**：输入管理员密码（`0252640`）可重置任意账号密码为 `123456`。
- **游客登录**：无需账号快速体验，但不提供模型对局功能，数据仅保存在本地浏览器。

> **注意**：通过 `file://` 和 `http://localhost:8080` 访问时，localStorage 数据互不相通，需要分别注册账号。

### 主菜单

登录后进入主菜单，包含：

- **开始游戏**：按当前设置新开一局。
- **继续游戏**：读取当前账号最近保存的存档，若无存档则新开一局。
- **游戏设置**：调整难度、对手、执子、形势判断、音效、背景音乐和读秒。
- **个人数据**：查看等级、经验、境界、胜负平统计。
- **排行榜**：查看天机困难榜与模型对局困难榜。
- **切换账号**：返回登录界面。
- **退出游戏**：提示关闭浏览器标签页。

### 对局操作

围棋规则：19×19 棋盘，黑白轮流落子，终局计算地盘。贴目 6.5 目。

底部按钮功能：

- **虚手（Pass）**：跳过本回合，连续双方虚手触发终局结算。
- **悔棋**：撤销最近两步（自己 + AI 各一步）。
- **认输**：直接判负。
- **存档**：保存当前对局进度，终局后不可存档。
- **返回**：返回主菜单，未保存进度会提示确认。

信息面板底部：

- **终局**：提前结束对局并结算当前地盘。
- **读秒框**：开启读秒时，在终局按钮上方居中显示剩余秒数。

### 游戏设置

| 设置项 | 说明 |
|--------|------|
| 难度 | 简单 / 中等 / 困难，天机 AI 的搜索深度与候选范围随之变化 |
| 对手 | 本地天机 / 模型对局（Ollama 大模型） |
| Ollama 地址 | 默认 `http://localhost:11434`，可自定义 |
| Ollama 模型 | 默认 `qwen3:8b`，可自定义 |
| 执子 | 执黑（先）/ 执白（后） |
| 形势判断 | 在棋盘上显示领地可视化 |
| 音效 | 落子与胜负音效开关 |
| 背景音乐 | 局内与局外自动切换不同 BGM |
| 读秒 | 不限 / 60秒 / 120秒 / 300秒，超时判负 |
| 注销账号 | 删除账号、排行榜记录和存档（不可逆） |

### 模型对局（Ollama）

在游戏设置中选择"对手: 模型对局"即可开启。切换时会弹出说明弹窗，提示使用前提条件。

模型会从本地引擎预选的合法候选落子点中做最终选择，优先提子/做活/占大场。模型连接失败时会自动回退到本地天机 AI 走棋，对手名显示"(已断开)"。

**使用前提**：

1. Ollama 已启动（终端运行 `ollama list` 确认模型已安装）
2. 通过 `http://localhost:8080` 访问本页面（非 `file://` 协议）
3. 对局信息栏会实时显示连接状态：
   - 绿色 `连接正常`：大模型调用成功
   - 红色 `Ollama连接失败`：请检查 Ollama 是否启动、地址是否正确
   - 金色 `思考中`：大模型正在计算走法

- 每个账号独立保存 Ollama 配置，存入浏览器 localStorage。
- 游客模式不提供模型对局。
- 模型对局比分会累积显示在右侧信息面板。

## 账号与密码

- 用户名：1–16 个字符，支持中文、字母、数字、下划线，不能使用 `Guest`。
- 密码：4–31 位，不能全为空格。
- 管理员密码：`0252640`，可用于重置任意账号密码。
- 注销账号会删除该账号、排行榜记录和存档。

## 数据存储

所有用户数据（账号、存档、战绩、设置）均保存在浏览器 `localStorage` 中，不会上传到任何服务器。更换浏览器或清空缓存会导致数据丢失。

## AI 系统

### 评估函数

评估每个落子位置的综合价值，包含：

- **气与活棋**：根据棋组气数评分，1气惩罚、2气微利、3气+50、4气+80；弱组（3子以上仅2气）额外加分
- **连接与展开**：独立棋子+15鼓励展开，单连接+25，多连接边际递减避免聚团
- **接触战**：接触敌方棋子且自身有连接时+30
- **提子威胁**：可吃1气敌组+350~500，可吃2气敌组+50
- **布局策略**：
  - 开盘（<12子）：星位+100，三线+50，二线+40，一线-30
  - 中盘（<40子）：边线+5~+20，中心区域+10
  - 官子（≥40子）：重视边线实地

### 搜索策略

| 难度 | 搜索方式 | 候选数 | 特点 |
|------|----------|--------|------|
| 简单 | 1层评估，70%随机取前5 | 40 | 适合新手 |
| 中等 | 1层极大极小搜索 | 18×12 | 考虑对手最优回应 |
| 困难 | 3层搜索（我→敌→我） | 20×12×8 | 深度分析，计算量适中 |

### 候选生成

搜索棋盘上已有棋子周围3格内的位置，评估每个候选的综合得分，优先考虑吃子、做活、占大场等关键着法。

## 技术说明

- 纯原生 HTML / CSS / JavaScript，无框架依赖，单文件运行。
- Canvas 2D 渲染棋盘与棋子。
- Web Audio API 生成落子与胜负音效。
- HTML5 `<audio>` 播放 BGM。
- 本地天机 AI 采用评估函数 + 多层搜索，三个难度级别。
- 所有异步 AI 调用均有错误保护，异常时自动恢复到玩家回合。
- 模型对局通过 Ollama `/api/chat` 接口调用本地大模型，失败自动回退本地 AI。
- `server.js`：Node.js 本地 HTTP 服务器，解决 `file://` → `http://localhost` 的 CORS 跨域限制。

## 已知限制

- **CORS 限制**：模型对局在 `file://` 协议下会失败。请通过本地 HTTP 服务器访问（`node server.js`）。
- **自动播放策略**：背景音乐首次加载可能被浏览器拦截，需用户先点击页面交互才能播放。
- **无痕模式**：`localStorage` 在隐私/无痕模式下不可用，会导致存档和账号数据丢失。
- **单文件架构**：所有数据存储在浏览器本地，更换浏览器或清空缓存会导致数据丢失，不支持多设备同步。
- **密码安全**：密码仅做本地哈希存储，无服务端验证，无法真正防止本地数据被篡改。
- **AI 局限**：本地天机 AI 基于评分函数与有限搜索，无法达到职业水平；模型对局质量取决于所用大模型。
