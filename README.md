# 凡人修仙传 · 五子棋

EasyX 图形库实现的古风五子棋/六子棋小游戏，包含账号系统、人机对战、排行榜、残局挑战、存档、密码重置和 GLM-5.1 模型对局功能。

## 运行环境

- Windows
- MinGW g++
- EasyX 图形库

## 快速启动

推荐直接使用根目录脚本：

```powershell
.\run.bat
```

该脚本会先编译根目录 `1.cpp`，生成 `1.exe` 后启动游戏。

只构建不运行：

```powershell
.\build.bat
```

如果你的 PowerShell 允许本地脚本，也可以使用：

```powershell
.\run.ps1
.\build.ps1
```

手动编译：

```powershell
g++ 1.cpp -o 1.exe -leasyx -lgdi32 -limm32 -lmsimg32 -lole32 -loleaut32 -lwinhttp -lcrypt32 -finput-charset=UTF-8 -fexec-charset=UTF-8
```

编译后运行：

```powershell
.\1.exe
```

## 游戏使用说明

进入游戏后先在登录界面选择登录、注册、修改密码、忘记密码或游客登录。注册账号后会记录经验、等级、排行榜战绩和个人存档；游客模式可以快速体验，但不提供模型对局。

主菜单包含开始游戏、残局挑战、继续游戏、游戏设置、个人数据、排行榜、切换账号和退出游戏。开始游戏会按当前设置进入一局新棋；继续游戏会读取当前账号最近保存的棋局；残局挑战提供固定残局目标。

对局中用鼠标左键点击棋盘交叉点落子。五子棋目标是连成五子，六子棋目标是连成六子；六子棋除首手外每回合需要落两子。底部按钮可用于悔棋、认输、提示开关、存档或返回主菜单；残局和模型对局中同一位置显示为换局。终局后点击棋盘可以重开。

游戏设置里可以调整难度、五子棋/六子棋规则、执黑/执白、禁手、提示、声音和限时。开启“大模型: GLM-5.1”前需要登录账号并配置 GLM-5.1 API Key。

个人数据页面展示等级、经验、胜负平、连胜和不同对局类型的数据。排行榜按胜场、胜率和局数综合排序，并区分普通天机对局与 GLM-5.1 对局。

## 账号与密码

用户名支持中文、字母、数字和下划线，不能使用 `Guest`。密码长度为 4-31 位，不能全为空格。

忘记密码功能需要管理员密匙。请在 `1.exe` 所在目录的 `data\admin_key.txt` 中写入一行密匙；如果该文件不存在或内容为空，程序会提示“管理员密匙尚未配置”，不会继续用空密匙重置密码。验证通过后，密码会被重置为 `123456`。

注销账号会删除该账号、排行榜记录、该账号存档和该账号本机保存的 GLM-5.1 API Key。

## GLM-5.1 模型对局

在游戏设置中选择“大模型: GLM-5.1”即可开启模型对局。首次开启时输入 GLM-5.1 API Key，程序会保存在当前 Windows 用户本机，并使用 Windows DPAPI 加密保护。

每个账号的 API Key 独立保存。游客模式不会保存或使用 GLM-5.1 API Key。

## 文件与数据目录

程序按 `1.exe` 所在目录读取背景图，请发布或移动时保持以下文件与 `1.exe` 同目录：

- `bg_login.png`
- `bg_menu.png`
- `bg_game.png`
- `bg_win.png`

运行数据和本地密钥统一保存到 `1.exe` 所在目录的 `data` 子目录，不再写入仓库根目录：

- `data\admin_key.txt`：管理员密匙文件，需要使用忘记密码功能时手动创建并写入。
- `data\users.dat`：注册账号后自动生成。
- `data\stats.dat`：产生对局结果后自动生成。
- `data\save_*.dat`：点击存档后自动生成，每个账号独立保存。
- `data\glm_key_*.dat`：开启模型对局并输入 GLM-5.1 API Key 后自动生成。
- `data\save.dat`：旧版单存档兼容文件，新版本不会主动生成。

如果旧版本已经在仓库根目录生成了 `users.dat`、`stats.dat`、`save.dat`、`admin_key.txt`、`save_*.dat` 或 `glm_key_*.dat`，新版本读取时会尽量迁移到 `data` 目录。仓库的 `.gitignore` 已忽略 `data/`。
