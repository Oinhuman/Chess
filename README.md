# 凡人修仙传 · 五子棋

纯前端单文件古风五子棋/六子棋游戏，无需后端、无需编译，浏览器直接打开即可游玩。包含账号系统、人机对战、排行榜、残局挑战、存档、模型对局与修仙境界系统。

## 运行方式

直接双击打开根目录下的 `index.html`，或在浏览器地址栏输入文件路径即可。

> 建议使用现代浏览器（Chrome、Edge、Firefox 等）以获得最佳体验。

## 文件说明

| 文件 | 说明 |
|------|------|
| `index.html` | 游戏主体，包含全部逻辑与样式，单文件即可运行 |
| `bg_login.png` | 登录界面背景 |
| `bg_menu.png` | 主菜单背景 |
| `bg_game.png` | 对局界面背景 |
| `bg_win.png` | 胜利结算背景 |
| `bg_lose.png` | 失败结算背景 |
| `bgm_in.mp3` | 对局内背景音乐 |
| `bgm_out.mp3` | 菜单/登录背景音乐 |

以上所有文件需与 `index.html` 放在同一目录下，游戏才能正常加载资源。

## 游戏使用说明

### 登录入口

进入游戏后，登录界面提供以下选项：

- **登录**：输入已注册的用户名和密码进入游戏。
- **注册**：创建新账号，记录经验、等级、战绩、存档和模型对局密钥。
- **修改密码**：验证旧密码后设置新密码。
- **忘记密码**：当前版本为本地 Demo，暂不支持重置他人密码。如需重置，可删除账号后重新注册。
- **游客登录**：无需账号快速体验，但不提供模型对局功能，数据仅保存在本地浏览器。

### 主菜单

登录后进入主菜单，包含：

- **开始游戏**：按当前设置新开一局。
- **残局挑战**：进入残局挑战选择界面。
- **继续游戏**：读取当前账号最近保存的存档，若无存档则新开一局。
- **游戏设置**：调整难度、规则、对手、执子、禁手、提示、音效、背景音乐和限时。
- **个人数据**：查看等级、经验、境界、胜负平、连胜、不同难度和规则统计。
- **排行榜**：查看天机困难榜与 GLM-4.7-flash 困难榜，支持五子棋/六子棋切换。
- **切换账号**：返回登录界面。
- **退出游戏**：提示关闭浏览器标签页。

### 对局操作

对局中点击棋盘交叉点落子：

- **五子棋**：黑棋先行，连五成阵即胜。可开启禁手（黑棋禁止双三、双四、长连）。
- **六子棋**：黑棋首回合落 1 子，之后每回合各落 2 子，先连六者胜。

底部按钮功能：

- **悔棋**：撤销最近一步（自己+AI 各一步）。
- **认输**：直接判负。
- **心眼提示**：在棋盘上标记攻防建议（守/攻）。
- **存档**：保存当前对局进度，终局后不可存档。
- **返回**：返回主菜单，未保存进度会提示确认。

对局结束后点击结算面板上的“点击继续”即可重开。

### 游戏设置

| 设置项 | 说明 |
|--------|------|
| 难度 | 简单 / 中等 / 困难，天机 AI 的搜索深度与候选范围随之变化 |
| 规则 | 五子棋 / 六子棋切换 |
| 对手 | 本地天机 / GLM-4.7-flash 模型对局（需登录账号） |
| 大模型 | 固定为 GLM-4.7-flash，支持配置 API Key |
| 禁手 | 五子棋下黑棋禁手开关，六子棋无禁手 |
| 执子 | 玄黑（先）/ 玉白（后） |
| 心眼提示 | 在棋盘上显示攻防建议标记 |
| 音效 | 落子与胜负音效开关 |
| 背景音乐 | 局内与局外自动切换不同 BGM |
| 步时 | 不限 / 10秒 / 30秒 / 60秒 |
| 注销账号 | 删除账号、排行榜记录、存档和 GLM 密钥（不可逆） |

### 残局挑战

提供 3 关随机生成的残局，每局限定手数内破局：

| 关卡 | 名称 | 限手 | 说明 |
|------|------|------|------|
| 1 | 残局·双活杀 | 2 手 | 两手内破双线杀，默认不显示提示 |
| 2 | 残局·攻守劫 | 2 手 | 白棋干扰更多，关键落点更隐蔽 |
| 3 | 残局·乱战局 | 2 手 | 乱战中找唯一攻势，容错更低 |

残局不会写入普通存档，对局内底部按钮显示为“换局”。

### 个人数据

统计维度：

- 境界与经验（炼气 → 筑基 → 结丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫 → 真仙）
- 总对局数、当前连胜、最高连胜
- 各难度（简单/中等/困难）胜负平
- 五子棋/六子棋局数与胜场
- 称号系统（根据战绩自动授予）
- 支持区分“天机数据”与“GLM-4.7-flash 数据”
- 支持重置本页数据

### 排行榜

按胜场、胜率、负场、总局数综合排序，仅展示困难难度数据。支持：

- 天机困难榜 / GLM-4.7-flash 困难榜 切换
- 五子棋 / 六子棋 切换

### 模型对局（GLM-4.7-flash）

在游戏设置中选择“对手: 模型对局”并输入 GLM-4.7-flash API Key 即可开启。模型会从本地引擎预选的合法候选落子点中做最终选择，优先立即取胜、其次防守、再攻连续威胁。

- 每个账号独立保存 API Key，存入浏览器 localStorage。
- 游客模式不提供模型对局。
- 模型对局比分会累积显示在右侧信息面板。
- 非本地 HTTP 环境（如直接打开文件）可能受 CORS 限制，建议通过 `http://localhost` 访问。

## 账号与密码

- 用户名：1–16 个字符，支持中文、字母、数字、下划线，不能使用 `Guest`。
- 密码：4–31 位，不能全为空格。
- 当前版本为本地 Demo，忘记密码功能暂不支持重置，可删除账号后重新注册。
- 注销账号会删除该账号、排行榜记录、存档和本机保存的 GLM-4.7-flash API Key。

## 数据存储

所有用户数据（账号、存档、战绩、设置、API Key）均保存在浏览器 `localStorage` 中，不会上传到任何服务器。更换浏览器或清空缓存会导致数据丢失。

## 技术说明

- 纯原生 HTML / CSS / JavaScript，无框架依赖，单文件运行。
- Canvas 2D 渲染棋盘与棋子。
- Web Audio API 生成落子与胜负音效。
- HTML5 `<audio>` 播放 BGM。
- 本地 AI 采用基于评分函数的候选生成 + Alpha-Beta 剪枝搜索。
